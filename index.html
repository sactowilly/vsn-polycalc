Derived geometry

Pallet Cover

Derives a bag width and bag length first, then calculates the theoretical bag weight from that geometry.

Film Assumptions

Derived bag width = pallet length + pallet width + slack. Derived bag length = pallet height + half pallet width + overhang.

Derived geometry

Drum Liner

Derives bag geometry from drum circumference, top allowance, and seal slack before calculating theoretical weight.

Film Assumptions

Derived bag width = drum circumference plus slack. Derived bag length = drum height + drum radius + overhang.
